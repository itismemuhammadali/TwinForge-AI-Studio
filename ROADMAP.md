# AIMR Twin Studio™ — Mobile App Roadmap

## Phase 1 — Mobile App
- Complete mobile UI redesign with clean modern navigation
- Existing image generation (same models and API as current website)
- User authentication with email verification and password reset
- Content library for saving and accessing generated images
- In-app subscriptions and credit pack purchases

## Phase 2 — Carousel & B-Roll
- **Carousel Generator** — turn images into ready-to-post social media carousels with templates and text overlays
- **B-Roll Video Generator** — convert images into short cinematic clips using Kling API
  - Motion styles: slow camera push, side pan, cinematic reveal

## Phase 3 — Talking Head Videos
- AI voice generation using **ElevenLabs**
- Lip sync using **Kling** + final video stitching using **Sync.so**
- Flow: upload image → write script → generate complete talking head video in-app

## Video Templates Note
- For dynamic templates with effects, beat sync, and music → **Creatomate** integration
  - Rich template library, each template has its own style, effects, and music
  - Plug in photo → video generated automatically
- For simple cinematic style (walk shots, coffee shop, airport scenes) → **Kling API** alone is sufficient
